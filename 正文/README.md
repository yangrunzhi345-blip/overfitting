## 二、 执笔铁律快速自检清单（遵照 AGENTS.md）

1. **章纲前置约束**：动笔前必须调阅目标章节的 `第XXX章_标题.md` 细纲，严格依照限定的“核心剧情、博弈焦点与章末落点”执笔；
2. **第一人称知识边界**：整部小说由陆令仪第一人称（“我”）统摄，严禁全知视角泄露；
3. **字数硬边界**：单章必须在 2600—3000 字之间，严禁突破 3000 字；
4. **拒绝天气开篇**：直接从动作、对白、突发物理声响或一句突兀的事实切入；
5. **拒绝升华收尾**：章末必须落在具体客观动作、金属碰撞、器物回声或未熄灭的屏幕光上，写完立刻收刀。
