# 文笔规范：09_语言辨识度

> **核心维度**：语言辨识度  
> **具体要求**：构建清晰的角色“声纹特征”与稳定的第一人称文风，抹掉名字也能精准辨析说话人  
> **应避免的AI倾向**：千人一面、千章一律，所有角色和章节共用一套平庸、扁平的AI说明文语调

---

## 一、 核心审美法则

**成熟写作的第一标志，是角色拥有无可替代的“声纹”。**  
AI最大的通病是“同质化”——无论是十二岁的小男孩、四五十岁的纪检律师，还是沪上名媛，开口闭口全是一模一样的四字成语、主谓宾齐全的欧化长句。

在《过度拟合》中，必须建立严格的**“声线隔离防火墙”**：抹掉说话人名字，读者仅凭标点、句式长度、词汇习惯就能一眼看出是谁在开口。

```mermaid

    class 陆令仪_声纹 {
        文风: 清冷自持 / 唯物辩证 / 书香清雅

        句式: 先因后果 / 略带古典韵律的平直陈述
    }
    class 沈策_声纹 {
        文风: 冷肃短促 / 工科指令化 / 示弱时沙哑

        句式: 极短单句 / 几乎不用虚词 / 动词主导
    }
    class 闻芷_声纹 {
        文风: 绵里藏针 / 优雅松弛 / 调侃挑弄
        词汇: 好不好呀 / 有意思 / 烟雨 / 骨相 / 乖
        句式: 尾音微扬的反问句 / 柔软从容的倒装
    }
```

## 三、 正反案例深度对照

### 场景：关于“中考前是否参加省队奥数集训”的三人不同表达

#### ❌ 典型 AI 腔（千人一面、人人皆为同一种文绉绉调调）
* 陆令仪说：“我觉得这次集训非常重要，我们应该认真准备，争取在集训中取得优异的成绩。”
* 沈策说：“是的，姐姐说得对，我一定会全力以赴地去参加集训，不会辜负大家的期望。”
* 闻芷说：“集训固然重要，但我认为我们也需要注意劳逸结合，保持良好的心态最关键。”

#### ✅ 《过度拟合》规范写法（声纹鲜明，风格立判）
* **沈策**（手里的铅笔在图纸上轻叩一下，头都没抬）：  
  > “名单定了。我俩挨着。票我已经让我妈打好了，下周三早晨七点的高铁，车厢倒数第二排，靠窗。”
* **陆令仪**（把刚批阅完的卷子对折抚平，微扬下颌）：  
  > “谁答应跟你坐一块儿了？把全国联赛第二轮的函数错题订正完再跟我提集训的事。下楼骑车把头盔扣紧。”
* **闻芷**（倚在门边轻晃着手里的白檀香水小样，眼波含笑）：  
  > “天天算那些死板的重力加速度，不嫌闷呀？令仪，集训基地隔壁就是当代美术馆，周末溜出来，我带你去看现代芭蕾彩排，嗯？”
